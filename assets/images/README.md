# Artwork drop-in folder

Every artwork slot on the website is a labelled placeholder plate until the real
file exists here. Drop the file in at the exact path printed on its plate
(and listed in `/ASSETS-TO-PROVIDE.md`) - the site picks it up automatically,
no code change needed.

Sub-folders:
- `characters/`  character dossier art (Mahasona)
- `folklore/`    demon sculpt previews used by the folklore viewer + bestiary
- `gallery/`     media archive images
- `game/`        gameplay / studio imagery
- `locations/`   world location imagery
- `hero/`        optional cinematic hero backdrop
- `mascot/`      the Moha mascot (wired through `assets/js/site-config.js`)
- `textures/`    reserved for optional overlay textures

Recommended: JPG/WebP, sRGB, 1600px wide max for full-bleed, 900px for cards.
